# Dataset Notes

## Source

Dataset: Network operator KPIs time series dataset  
Source: <https://zenodo.org/records/8147768>

## Domain

The dataset contains anonymized network operator KPI time-series data.

## Planned Use

This project uses the dataset for:

- KPI inspection
- schema validation
- time-series forecasting
- residual-based anomaly scoring
- backend API demonstration

## Data Handling Rules

- Raw files are stored under `data/raw/`.
- Raw files are not committed to Git.
- Cleaned files are generated by scripts.
- Dataset assumptions are documented before modeling.
- Any validation failure must stop downstream processing.

## Limitation

The dataset is public, anonymized, and scaled. It is not private Indonesian operator data.
